# Systems

The systems the organisation uses and the personal data each one holds. Write one section per system, with the name of the system as its heading. Say in prose what the system is used for, what personal data it holds and about whom, who is responsible for it and who supplies it.

## Example: Payroll system

This section is an example, not a fact about the organisation. Replace it with a real section or delete it.

The payroll system is used to pay salaries. It holds the names, national identity numbers, bank account numbers and salaries of all employees. The head of finance is responsible for it. Example Payroll AS supplies and runs it.
